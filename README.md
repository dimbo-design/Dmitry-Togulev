## About the site

Old-school static site — pure HTML/CSS + minimal vanilla JS. No frameworks, no build step.

Page covers:
- Hero with positioning
- Visual portfolio (masonry grid with hover/tap captions)
- One developed case (KazanExpress · warehouse intake)
- Project tile (MythHand)
- Experience timeline (10+ years)
- Contacts with copy-to-clipboard email and PDF download

## Stack

- **HTML5 / CSS** — all styles in single `<style>` block inside `index.html`
- **Vanilla JS** — clipboard copy, scroll-triggered right-header reveal, accordion in case-tile with rAF-animated grid row-span
- **Font**: Fixel Display (OTF, weights 400–700)
- **No build, no dependencies**
- **Hosted on GitHub Pages**

## Files

- `index.html` — main page (HTML + CSS + JS in one file)
- `assets/` — images, fonts, downloadable PDF
- `fonts/` — Fixel Display OTF files

## Notes

- Single-file architecture by choice — portability + zero ceremony.
- The site is a **teaser**; the [PDF resume](https://dimbo-design.github.io/Dmitry-Togulev/assets/Product_Design_Dmitry_Togulev.pdf) is the deeper document.
